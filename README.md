# katiekinkel.com

Personal site for **Katie Kinkel** — AI-fluent QA & operations generalist.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- `next-themes` (light / dark / system)
- Vercel deploy · domain `katiekinkel.com`

## Scripts

```bash
npm install
npm run generate:resume   # DOCX + PDF via LibreOffice
npm run dev
npm run build
```

## Resume downloads

- [`/Katie-Kinkel-Resume.pdf`](./public/Katie-Kinkel-Resume.pdf)
- [`/Katie-Kinkel-Resume.docx`](./public/Katie-Kinkel-Resume.docx)

Use **Print** in the header for a résumé-only print layout.
